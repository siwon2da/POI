POI · Power Of Imagination

코드가
문장처럼 읽힌다

우리가 만든 언어. 처음 배우는 사람도 한 줄로 이해하고, 전문가는 끝까지 씁니다. 자체 문법·타입·오류·GUI 를 갖고, 실행은 세계에서 가장 검증된 런타임 위에서 합니다.

바로 시작하기 GitHub 보기

$ poi run hello.poi

hello.poi 
name = ask "이름이 뭐예요?"

if name.length >= 2 {
    show "반가워요, {name}님"
} else {
    show "이름이 너무 짧아요"
}

왜 POI 인가

문법이 쉬운 언어는 대개 할 수 있는 게 적습니다. POI 는 셋 다 잡습니다 — 쉽고, 넓고, 끝까지.

01

문법 자체가 쉽습니다

print() 괄호, range(), f"", 세미콜론, import — 처음엔 하나도 몰라도 됩니다. 읽으면 뜻이 보입니다.

repeat 3 as i {
    show "{i}번째"
}

fn double(x) => x * 2
if age between 10 and 19 { show "10대" }
02

입문자에서 전문가까지, 한 언어로

타입 표기·파이프라인·비동기·선택적 정적 타입은 필요할 때만 꺼내 씁니다. 같은 언어 안에서 실력만큼 올라갑니다.

# 처음엔 이렇게
total = a + b

# 나중엔 이렇게도
fn add(a: Int, b: Int) -> Int => a + b
nums |> filter("> 0") |> take(10)
03

세상의 모든 파이썬 라이브러리가 곧 POI 라이브러리

새 언어인데 첫날부터 라이브러리 수십만 개. numpy·pandas·torch·requests·opencv — use py: 한 줄이면 끝.

use py:numpy as np
data = np.array([1, 2, 3, 4])
show data.mean()      # 2.5

오류가 사람의 말로 나옵니다

스택 트레이스를 그대로 던지지 않습니다. 어디서·왜·어떻게 고치는지까지.

엔진이 실제로 뱉은 것: TypeError: can only concatenate str (not "int") to str POI Error P103 숫자와 문자를 함께 계산할 수 없습니다. 3 | money = "1000" > 4 | total = money + 500 ^ 5 | show total 해결: number(...) 로 문자열을 숫자로 바꾸거나, text(...) 로 숫자를 문자열로 바꿔 맞추세요.

모든 오류에 코드가 붙습니다

P0xx 는 컴파일 단계, P1xx 는 실행 단계. 코드로 검색하면 바로 원인과 해결이 나옵니다.

P101 0으로 나눔P102 모르는 이름P104 파일 없음 P106 목록 범위P110 숫자 변환 실패

막히면, 안이 보입니다

v1.1 부터 디버깅이 언어에 들어왔습니다. 코드를 고치지 않고도 흐름과 값을 들여다봅니다.

inspect · watch

값의 속을 그 자리에서

inspect(x) 는 타입·구조·길이를 예쁘게 찍고, watch(x) 는 찍으면서 x 를 그대로 흘려보냅니다 — 한 줄도 안 끊깁니다.

watch(cart)          # List  3개 …
final = watch(total_with_tax(cart))
poi run --trace --vars

문장마다, 변수가 바뀔 때마다

실행되는 줄과 소스를 그대로 찍고, 값이 바뀌면 → total = 4600 처럼 보여줍니다. poi debug 는 여기에 오류 사후 분석까지 한 번에.

╎  11 │ total = total + item
╎      → total = 4600
╎      → item  = 900
pause() · --explain

멈춰서 물어본다

pause() 는 그 줄에서 멈춰 지역 변수를 보여주고, 식을 쳐보게 하고, 계속합니다. --explain 은 오류가 난 순간의 값들까지 되짚어 줍니다.

⏸  일시정지 (줄 12)
│ 지역 변수: base, rate, tax

새 언어인데, 첫날부터 라이브러리 수십만 개

POI 는 자체 문법·타입·오류·GUI 모델을 가진 독립 언어입니다. 실행만 세계에서 가장 검증된 런타임 위에서 하기 때문에, 만들자마자 파이썬 생태계 전부를 물려받습니다. 성능도 그만큼 나옵니다.

파이썬보다 자유롭게

중괄호도, 들여쓰기도 강제하지 않습니다. 같은 블록을 세 가지로 쓸 수 있고, 섞어도 됩니다.

중괄호

익숙하면 그대로

다른 언어에서 오셨다면 { } 를 쓰면 됩니다.

if x > 0 {
    show "양수"
}
콜론 한 줄

짧으면 한 줄

한 문장이면 : 뒤에 바로.

if x > 0: show "양수"
repeat 5 as i: show i
end 로 닫기

중괄호도 들여쓰기도 없이

블록 끝에 end 만. 들여쓰기는 순전히 장식입니다. if / else if / else 는 체인 전체를 하나의 end 로.

fn 인사(이름)
return "안녕, " + 이름
end

if 점수 >= 60
show "합격"
else
show "재시험"
end

테스트가 언어 안에

test · assert · poi test

파일 안에 test 블록. poi test 로 통과/실패 요약, 실패하면 exit 1. 일반 실행 땐 정의만 하고 안 돌립니다.

fn add(a, b) => a + b

test "덧셈"
assert add(2, 3) == 5
assert add(-1, 1) == 0
end
모듈 · 표준 라이브러리

여러 파일, 정규식, CSV, 통계

use "./유틸.poi" 로 파일을 나누고, regex·csv·datetime·stats·random 은 import 없이.

use "./유틸.poi" as u

rows = csv.parse(file.read("data.csv"))
avg  = rows |> map(r => number(r.score)) |> avg
show stats.median([3, 1, 4, 1, 5])
