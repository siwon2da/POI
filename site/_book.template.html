POI 입문서

설치부터 GUI · 디버깅 · 외부 라이브러리까지. 예제는 전부 그대로 실행됩니다. poi run 파일.poi 로 따라 해 보세요.

0. 이 책은

프로그래밍을 처음 하는 사람을 위한 책입니다. 미리 알아야 할 건 없습니다. 각 장은 짧은 설명 → 실행되는 예제 → 해보기 로 되어 있습니다. 순서대로 읽으면 됩니다.

POI 는 우리가 만든 언어입니다. 자체 문법·타입·오류·GUI 를 갖고, 실행만 세계에서 가장 검증된 런타임 위에서 합니다. 그래서 새 언어인데도 세상의 라이브러리 수십만 개를 첫날부터 씁니다.

1. POI 세우기

설치 마법사나 poi.exe 하나면 됩니다. 준비물 없음.

# Windows — 설치 마법사
poi-setup-1.18.0.exe

# 포터블 — poi.exe 하나만
poi.exe run 파일.poi

# 묶음 — poi-1.18.0.zip 을 풀어서
poi.exe run examples/basics.poi

모두 hagora.kr/poi 에서 받습니다. 새 버전이 나오면 poi run 이 알려주고, poi update 로 올립니다.

2. 첫 프로그램

hello.poi 파일을 만들고:

show "Hello World"
show 2 + 3
# # 뒤는 주석 — 실행되지 않습니다

poi run hello.poi 하면 Hello World 와 5 가 나옵니다. print() 도, 괄호도, 세미콜론도 필요 없습니다.

해보기 — 자기 이름과 좋아하는 숫자를 각각 한 줄로 출력해 보세요.

3. 값과 변수

name = "시원"       # 글자 (Text)
age = 16            # 정수 (Int)
height = 172.5      # 실수 (Float)
alive = true         # 참/거짓
nothing = null       # 없음

const PI = 3.14159  # 안 바뀌는 값은 const

이름은 한글로도 됩니다. 이름 = "시원" 도 정상입니다.

해보기 — 좋아하는 음식 이름과 가격을 변수에 담아 출력해 보세요.

4. 문자열

중괄호로 값을 문장에 끼워 넣습니다 (보간).

name = "시원"
show "안녕하세요 {name}님, 반갑습니다"

show name.length          # 2
show "poi".upper()        # POI
show "Hello".reverse()    # olleH
show "바나나".contains("나")  # true
show "a b c".words()      # [a, b, c]

그밖에 .lower() .trim() .starts_with(s) .ends_with(s) .is_empty 가 있습니다.

5. 계산

show 2 + 3 * 4      # 14 (곱셈 먼저)
show (2 + 3) * 4    # 20
show 10 / 4          # 2.5
show 10 % 3          # 1 (나머지)

show math.sqrt(144)   # 12.0
show math.round(math.pi, 2)  # 3.14

math 는 import 없이 바로 씁니다: floor ceil abs min max random randint(a,b) …

6. 물어보기

name = ask "이름이 뭐예요? "
show "{name}님 환영합니다"

age = number(ask "나이는? ")   # ask 는 항상 글자 → number() 로 변환
show "내년엔 {age + 1}살"

7. 조건

age = 16
if age >= 18 {
    show "성인"
} else if age >= 13 {
    show "청소년"
} else {
    show "어린이"
}

if age between 10 and 19 { show "10대" }
if name is "시원" { show "어서와" }

grade = "통과" if score >= 60 else "재시험"   # 삼항식

연결어는 and or not. 1 < x and x < 10 처럼 이어서 씁니다.

블록은 3가지 — 중괄호 { }, 한 줄이면 콜론 if x > 0: show "양수", 아니면 end 로 닫기(중괄호도 들여쓰기도 필요 없음). if / else if / else 는 체인 전체를 하나의 end 로 닫습니다.
# 셋 다 같은 뜻
if x > 0 { show "양수" }
if x > 0: show "양수"
if x > 0
show "양수"
end

8. 반복

repeat 3 {
    show "안녕"
}
repeat 5 as i {          # i 는 0,1,2,3,4
    show i + 1
}
for x in [10, 20, 30] {
    show x
}

# 합 구하기
total = 0
for x in [3, 1, 4, 1, 5] {
    total = total + x
}
show total          # 14

9. 함수

fn add(a, b) {
    return a + b
}
show add(3, 4)          # 7

fn double(x) => x * 2   # 한 줄 함수
fn greet(name, msg = "안녕") => msg + ", " + name  # 기본값

show greet("시원")        # 안녕, 시원
show greet("예성", "반가워")  # 반가워, 예성

10. 목록

nums = [3, 1, 4, 1, 5]
show nums.length        # 5
show nums.first         # 3
show nums.last          # 5
nums.add(9)
show nums.sort().join("-")   # 1-1-3-4-5-9

# 짝수만 골라 담기
even = []
for x in nums {
    if x % 2 is 0 { even.add(x) }
}
show even

11. 객체

user = { name: "시원", age: 16, admin: true }
show user.name          # 시원  (user["name"] 안 해도 됨)
user.age = 17

show user?.nick ?? "별명없음"   # 없는 값은 안전하게
show user.has("name")          # true

people = [
    { name: "시원", age: 16 },
    { name: "예성", age: 17 }
]
for p in people {
    show "{p.name} ({p.age})"
}

14. 오류 다루기

try {
    text = file.read("없는파일.txt")
} catch error {
    show "실패: {error}"
}

POI 는 스택 트레이스를 그대로 던지지 않습니다. 대신 P-코드 + 줄 + 힌트:

POI Error P103
  숫자와 문자를 함께 계산할 수 없습니다.
    4 | total = money + 500
  해결: number(...) 로 문자열을 숫자로 바꾸세요.

15. 디버깅

show "--- inspect ---"
inspect(user)                 # 타입·구조·길이를 예쁘게, user 를 그대로 반환
final = watch(add(total, 10))  # 값 보면서 흘려보내기
# pause()                     그 줄에서 멈춰 지역 변수 보기

실행할 때: poi run x.poi --trace (문장마다), --vars (변수 변화까지), --explain (오류 시 그때 값들), poi debug x.poi (전부).

16. 창 만들기

app "로그인" {
    window { size: 380x320  center: true }
    state username = ""

    column {
        title "로그인"
        input "아이디" -> username
        password "비밀번호" -> pw
        button "로그인" {
            show "환영합니다 {username}님"
        }
    }
}

배치는 column(세로) · row(가로) · card. 이벤트는 on "start" { } · on "close" { }.

17. 외부 라이브러리

POI 안에서 세상의 라이브러리를 그대로 불러 씁니다.

use py:이름 as 별칭   # 외부 라이브러리 한 줄
값 = 별칭.함수([1, 2, 3])
show 값

python {               # 필요하면 저수준 코드도 그대로
    import sys
    print(sys.version)
}

use pyfile "./ai.py"   # 내 스크립트 파일도
플레이그라운드(브라우저 실행)에서는 안전을 위해 이 장의 기능이 잠깁니다. 내 컴퓨터에서는 전부 됩니다.

18. 프로젝트

poi new my-app
cd my-app
poi run                # src/main.poi 를 실행

poi.toml 에 이름·버전·의존성이 들어갑니다. poi build로 Python 설치 없이 단일 실행파일을 만듭니다.
