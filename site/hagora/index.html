파이썬을 숨긴 게 아니라,
파이썬 위에 사람을 얹었다.

POI 코드는 파이썬 소스로 트랜스파일돼 CPython 에서 돕니다. 그래서 numpy · pandas · requests 를 그대로 쓰면서, 문법 · GUI · 오류 메시지는 훨씬 쉽습니다.

GitHub 에서 보기 → 내려받기 · 실행
$ python -m poi run examples/basics.poi
greet.poi → 파이썬 ✓ compiled

네 개의 축

쉬운 문법 · 파이썬 호환 · 내장 UI · 사람 친화 오류

이 네 가지가 제대로 되면 “파이썬 문법만 바꾼 장난감”이 아니라, 쓸 이유가 있는 언어가 됩니다.

01

읽으면 뜻이 보이는 문법

print() 괄호, range(), f"" 없이. 인간이 쓰는 말에 가깝게.

repeat 3 as i {
    show "{i}번째 인사"
}

fn double(x) => x * 2
if age between 10 and 19 { show "10대" }
02

파이썬 생태계를 그대로

수십만 개의 파이썬 라이브러리가 곧 POI 라이브러리. 필요하면 파이썬 코드도 그대로 삽입.

use py:numpy as np
data = np.array([1, 2, 3, 4])
show data.mean()        # 2.5

python { # 탈출구
    import os
    print(os.getcwd())
}
03

GUI 가 언어 기본기

Tkinter · PyQt 없이. 선언형으로 창 하나가 Hello World 다음 순서.

app "안녕" {
    window { size: 420x260 }
    text "이건 POI 로 만든 창"
    button "눌러봐" {
        show "버튼 눌림!"
    }
}
04

오류는 사람의 말로

파이썬 traceback 을 그대로 던지지 않습니다. POI 줄 + 한국어 설명 + 해결 힌트.

# 파이썬:
# TypeError: can only concatenate str...

# POI:
POI Error P103
  숫자와 문자를 함께 계산할 수 없습니다.
  → number(...) 로 바꿔보세요.
동작 원리

새 VM 을 만들지 않습니다. CPython 이 런타임입니다.

POI 소스는 파서를 거쳐 POI AST 가 되고, 그 AST 를 파이썬 소스로 옮긴 뒤 compile() 해서 실행합니다. 성능은 거의 파이썬 급이고, 실행 중 오류가 나면 파이썬 줄번호를 POI 줄번호로 되돌려(linemap) 사람이 읽을 메시지를 만듭니다.

사람 친화 오류

P103 — 숫자와 문자를 함께 계산할 수 없습니다

POI Error P103 숫자와 문자를 함께 계산할 수 없습니다. 3 | money = "1000" > 4 | total = money + 500 ^ 5 | show total 해결: number(...) 로 문자열을 숫자로 바꾸거나, text(...) 로 숫자를 문자열로 바꿔서 맞추세요.

코드 · 줄 · 원인 · 해결

모든 오류에 P-코드가 붙습니다 (P101 0으로 나눔, P102 모르는 이름, P104 파일 없음 …). 컴파일 단계 오류는 P0xx, 실행 단계는 P1xx.

밑에서 실제로 난 파이썬 예외: TypeError: can only concatenate str (not "int") to str

입문자가 traceback 을 보고 도망가지 않도록, 이 번역 계층이 v0.1 부터 들어가 있습니다.

내장 GUI

Flutter · SwiftUI 처럼 선언형. 백엔드는 tkinter.

fn login(id, pw) {
    if id.length >= 2 and pw.length >= 4 {
        show "로그인 성공: {id}"
    }
}

app "로그인" {
    window { size: 380x320  center: true }

    state username = ""
    state password = ""

    column {
        title "로그인"
        input "아이디" -> username
        password "비밀번호" -> password
        button "로그인" {
            login(username, password)
        }
    }
}

설치 · 실행

파이썬만 있으면 됩니다. 외부 의존성 0.

1
저장소를 받습니다
git clone https://github.com/siwon2da/POI.git
2
바로 실행 (설치 없이)
python -m poi run examples/basics.poi
3
또는 설치해서 poi 명령으로
pip install -e .  &&  poi repl
4
새 프로젝트 시작
poi new my-app  &&  cd my-app  &&  poi run
poi run [파일.poi]실행 (기본 src/main.poi)
poi run x.poi --emit-python변환된 파이썬 보기
poi new <이름>프로젝트 생성
poi check <파일>문법 검사
poi repl대화형 셸
poi version버전

POI 는 파이썬을 죽이는 언어가 아니라, 파이썬을 엔진으로 쓰고 그 위에 더 쉬운 언어를 씌운 것.

poi> show test # → 아스키아트: "강하고 담대하라 … 여호수아 1:9"
poi> show pp청춘 # → 청춘
