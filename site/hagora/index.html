POI · Power Of Imagination

코드가
문장처럼 읽힌다

우리가 만든 언어. 처음 배우는 사람도 한 줄로 이해하고, 전문가는 끝까지 씁니다. 자체 문법·타입·오류·GUI 를 갖고, 실행은 세계에서 가장 검증된 런타임 위에서 합니다.

바로 시작하기 GitHub 보기

$ poi run hello.poi

hello.poi 
name = ask "이름이 뭐예요?"

if name.length >= 2 {
    show "반가워요, {name}님"
} else {
    show "이름이 너무 짧아요"
}

왜 POI 인가

문법이 쉬운 언어는 대개 할 수 있는 게 적습니다. POI 는 셋 다 잡습니다 — 쉽고, 넓고, 끝까지.

01

문법 자체가 쉽습니다

print() 괄호, range(), f"", 세미콜론, import — 처음엔 하나도 몰라도 됩니다. 읽으면 뜻이 보입니다.

repeat 3 as i {
    show "{i}번째"
}

fn double(x) => x * 2
if age between 10 and 19 { show "10대" }
02

입문자에서 전문가까지, 한 언어로

타입 표기·파이프라인·비동기·선택적 정적 타입은 필요할 때만 꺼내 씁니다. 같은 언어 안에서 실력만큼 올라갑니다.

# 처음엔 이렇게
total = a + b

# 나중엔 이렇게도
fn add(a: Int, b: Int) -> Int => a + b
nums |> filter("> 0") |> take(10)
03

세상의 모든 파이썬 라이브러리가 곧 POI 라이브러리

use py:numpy as np

show data.mean()      # 2.5

inspect · watch

값의 속을 그 자리에서

inspect(x) 는 타입·구조·길이를 예쁘게 찍고, watch(x) 는 찍으면서 x 를 그대로 흘려보냅니다 — 한 줄도 안 끊깁니다.

watch(cart)          # List  3개 …
final = watch(total_with_tax(cart))
poi run --trace --vars

문장마다, 변수가 바뀔 때마다

실행되는 줄과 소스를 그대로 찍고, 값이 바뀌면 → total = 4600 처럼 보여줍니다. poi debug 는 여기에 오류 사후 분석까지 한 번에.

╎  11 │ total = total + item
╎      → total = 4600
╎      → item  = 900

새 언어인데, 첫날부터 라이브러리 수십만 개

POI 는 자체 문법·타입·오류·GUI 모델을 가진 독립 언어입니다. 실행만 세계에서 가장 검증된 런타임 위에서 하기 때문에, 만들자마자 파이썬 생태계 전부를 물려받습니다. 성능도 그만큼 나옵니다.

파이썬보다 자유롭게

중괄호도, 들여쓰기도 강제하지 않습니다. 같은 블록을 세 가지로 쓸 수 있고, 섞어도 됩니다.

중괄호

익숙하면 그대로

다른 언어에서 오셨다면 { } 를 쓰면 됩니다.

if x > 0 {
    show "양수"
}
콜론 한 줄

짧으면 한 줄

한 문장이면 : 뒤에 바로.

if x > 0: show "양수"
repeat 5 as i: show i
end 로 닫기

중괄호도 들여쓰기도 없이

블록 끝에 end 만. 들여쓰기는 순전히 장식입니다. if / else if / else 는 체인 전체를 하나의 end 로.

fn 인사(이름)
return "안녕, " + 이름
end

if 점수 >= 60
show "합격"
else
show "재시험"
end

테스트가 언어 안에

test · assert · poi test

파일 안에 test 블록. poi test 로 통과/실패 요약, 실패하면 exit 1. 일반 실행 땐 정의만 하고 안 돌립니다.

fn add(a, b) => a + b

test "덧셈"
assert add(2, 3) == 5
assert add(-1, 1) == 0
end

웹은 언어 기본기입니다

v1.6–v1.7 은 백엔드를 겨냥합니다. poi run app.poi 하면 서버가 뜨고, CSRF·보안 헤더·레이트 리밋·gzip·비밀번호 해시·JWT·SQLite 가 처음부터 켜져 있습니다. 파이썬/JS 백엔드보다 짧고, 기본값이 더 안전하게.

내장 HTTP 서버

server { get "/" { } }

경로 파라미터 :id · query · body(JSON·폼 자동) · headers. 문자열이면 HTML, 객체면 JSON. respond · redirect · cookie · session.

server {
  get "/api/합/:a/:b" {
    return { 합: number(params.a) + number(params.b) }
  }
  post "/echo" { return body }
  static "./public"
}
선언형 페이지

webapp { page "/" { } }

heading·card·form·field·select… + state + action. 폼 제출 → 상태 갱신 → 재렌더(POST-redirect-GET). CSRF 토큰 자동 주입. 설정 0으로 반응형·다크 대응.

webapp "메모장" {
  state 메모 = []
  page "/" {
    heading "메모장"
    for m in 메모 { card { text m } }
    form "/추가" { field "새 메모" -> 내용  button "추가" }
  }
  action "/추가" { 메모.add(내용) }
}
백엔드·보안 라이브러리

import 없이 바로

crypto · password(PBKDF2) · jwt(HS256) · path · url · html · compress · log · cache · bench · dotenv · system · uuid. 전부 파이썬 표준 라이브러리 위, 외부 의존성 0.

h = password.hash("hunter2")       # 솔트 자동
password.verify("hunter2", h)     # → true (상수시간)
tok = jwt.sign({ uid: 7 }, 비밀, 3600)
jwt.verify(tok, 비밀)             # → {uid: 7} / null
데이터베이스

database(...) — 0설정 SQLite

파일 하나. 결과 행은 점 접근이 되는 객체. run · query · one · value · insert · tables. 안전 모드에선 차단.

db = database("app.db")
db.run("insert into note(body) values(?)", ["안녕"])
db.query("select * from note")   # → [{id:1, body:"안녕"}]

POI IDLE — POI 로 만든 편집기

코드 편집기를 POI 로 썼습니다. tkinter 위에서 순수 POI 문법(fn·if·for·문자열 보간·=> 람다)으로. 문법 강조, F5 실행(별도 스레드·8초 타임아웃), 열기/저장. poi idle 또는 poi build --app idle.

바로 실행

poi idle

설치돼 있으면 명령 한 줄. 예제가 열린 채로 뜨고, F5 로 실행됩니다.

$ poi idle
$ poi build --app idle   # → dist/poi-idle.exe
