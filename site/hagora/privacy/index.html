POI 개인정보처리방침

시행일: 2026년 9월 9일

한생(HANSAENG, 이하 "회사")은 POI 언어 및 관련 도구·웹사이트(https://hagora.kr/poi/, 이하 "서비스")를

운영하면서 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목과 방법

POI 는 설치형 도구이며, 코드는 이용자의 컴퓨터에서 실행됩니다. 회사는 원칙적으로 개인정보를

수집하지 않습니다. 다음의 경우에 한해 최소한의 정보가 처리됩니다.

  • 플레이그라운드에 입력한 코드는 실행을 위해 서버 메모리에서 처리되며, 별도의 데이터베이스에
구분항목수집 방법목적
웹사이트 방문접속 IP, 브라우저 종류, 방문 일시, 요청 경로웹 서버 자동 기록서비스 운영·보안·통계
플레이그라운드이용자가 입력한 코드(일시적), 실행 결과이용자 직접 입력코드 실행 결과 반환 (저장하지 않음)
버전 확인설치된 POI 버전poi 실행 시 자동(끌 수 있음: POI_NO_UPDATE_CHECK=1)새 버전 안내
ChatGPT 연동(선택)ChatGPT 계정 인증 토큰이용자가 poi haon login 실행 시 OAuth하온의 AI 응답 제공
문의이메일 주소, 문의 내용이용자가 이메일·이슈로 문의 시문의 응대

저장하지 않습니다. 실행은 샌드박스(--safe)와 프로세스 격리로 제한됩니다.

  • ChatGPT 인증 토큰은 이용자 컴퓨터의 ~/.poi/chatgpt.json 에만 저장되며(권한 0600),

회사 서버로 전송되지 않습니다. poi haon logout 으로 즉시 삭제됩니다.

  • 하온이 클라우드 LLM(Groq 등)을 사용할 때, 이용자가 하온에 보낸 질문·코드가 해당 LLM 제공자에게

전달될 수 있습니다. 로컬 LLM(Ollama) 사용 시에는 외부 전송이 없습니다.

2. 개인정보의 보유 및 이용 기간

  • 웹 서버 접속 기록: 최대 6개월 보관 후 파기(보안 사고 조사 목적).
  • 플레이그라운드 코드: 실행 완료 즉시 메모리에서 소멸.
  • 문의 관련 정보: 문의 처리 완료 후 1년 보관 후 파기.
  • 관계 법령에서 별도 보관을 요구하는 경우 해당 기간을 따릅니다.

3. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

  • 이용자가 선택적으로 ChatGPT 연동 또는 클라우드 LLM 기능을 사용하여, 그 입력이 해당 AI

제공자(OpenAI, Groq 등)에게 전달되는 경우. 각 제공자의 개인정보처리방침이 적용됩니다.

  • 법령에 근거하거나 수사기관의 적법한 요청이 있는 경우.

4. 개인정보 처리의 위탁

현재 위탁하는 업무는 없습니다. 웹 호스팅은 회사가 직접 운영하는 서버에서 이루어집니다.

5. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 열람·정정·삭제·처리정지를 요구할 수 있습니다.

아래 연락처로 요청하시면 지체 없이 조치합니다.

  • 브라우저 로그·통계는 개인을 식별하지 않는 형태로 처리되며, 개별 삭제 요청 시 접속 IP를 기준으로 파기합니다.
  • ChatGPT 토큰·설정 파일은 이용자가 직접 ~/.poi/ 폴더에서 삭제할 수 있습니다.

6. 개인정보의 안전성 확보 조치

  • 전송 구간 암호화(HTTPS), 접속 기록의 접근 통제 및 최소 보관.
  • 인증 토큰은 로컬 저장·파일 권한 제한, 로그·오류 메시지에 노출하지 않음.
  • 플레이그라운드는 샌드박스 + 프로세스 격리 + 실행 시간·출력량 제한.

7. 개인정보 보호책임자 및 연락처

  • 사업자 정보는 한생 대표 사이트(hagora.kr)에 고지된 바를 따릅니다.
