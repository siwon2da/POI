# POI 오류 코드표

POI 는 파이썬 traceback 을 그대로 보여주지 않는다. 대신:

```
POI Error P103

  숫자와 문자를 함께 계산할 수 없습니다.

    3 | money = "1000"
  > 4 | total = money + 500
    5 | show total

해결:
  number(...) 로 문자열을 숫자로 바꾸거나,
  text(...) 로 숫자를 문자열로 바꿔서 맞추세요.
```

## 컴파일 단계 (P0xx)

| 코드 | 뜻 |
|---|---|
| P001 | 알 수 없는 글자 |
| P002 | 닫히지 않은 문자열 |
| P003 | 닫히지 않은 `python { }` 블록 |
| P010 | 필요한 토큰이 안 옴 (괄호/중괄호 짝) |
| P011 | 닫히지 않은 `{ }` 블록 |
| P012 | 대입 왼쪽이 변수/`a.b`/`a[0]` 가 아님 |
| P013 | 닫히지 않은 `app { }` |
| P014 | 표현식이 와야 할 자리에 다른 토큰 |
| P015 | 객체 리터럴 키 이름 누락 |
| P020 | 아직 지원 안 하는 문장 |
| P021 | 없는 표준 모듈 (`use xxx`) |
| P022 | 아직 지원 안 하는 표현식 |
| P023 | 기본값 매개변수 뒤에 필수 매개변수를 선언함 |
| P024 | 같은 함수 매개변수 이름을 중복 선언함 |
| P098 | 트랜스파일 결과 파이썬 문법 오류 (버그거나 `python{}` 오타) |

## 실행 단계 (P1xx)

| 코드 | 뜻 | 파이썬 대응 |
|---|---|---|
| P101 | 0 으로 나눔 | ZeroDivisionError |
| P102 | 모르는 이름 | NameError |
| P103 | 숫자와 문자 섞어 계산 | TypeError |
| P104 | 파일 없음 | FileNotFoundError |
| P105 | 없는 항목(키) | KeyError |
| P106 | 목록 범위 초과 | IndexError |
| P107 | 없는 기능(속성) | AttributeError |
| P108 | 재귀가 너무 깊음 | RecursionError |
| P110 | 숫자로 변환 실패 | `number()` |
| P120 | 그 자료형에 없는 편의 기능 | `poi_getattr` |
| P130 | `use pyfile` 로드 실패 | |
| P140 | JSON 형식 오류 | |
| P141 | 웹 요청 실패 | URLError |
| P199 | 그밖의 파이썬 예외 (원문 표시) | |
| P200 | tkinter 없음 | |
| P201 | 디스플레이 못 엶 | TclError |
| P370~P374 | Arduino 직렬 연결·센서 응답·회로 계산 오류 | `electronics` |
| P380~P385 | 보안 연구 입력·대상·점검 범위 오류 | `security` |

## 타입 검사 (P4xx — `poi check --types` / `poi run --types`)

| 코드 | 뜻 |
|---|---|
| P400 | 타입 붙은 선언에 다른 타입 값 (`x: Int = "hi"`) |
| P401 | `Text + Int` — 문자와 숫자를 + 로 |
| P402 | `Text` 에 `- * / %` 산술 |
| P403 | 함수 인자 자리에 다른 타입 |
| P404 | 함수 인자 개수 초과 |
| P405 | 선언한 반환 타입과 실제 반환값 타입 불일치 |
| P406 | `assert` 조건이 `Bool`이 아님 |
| P407 | `assert` 실패 설명이 `Text`가 아님 |
| P408 | `if`·`while`·삼항식 조건이 `Bool`이 아님 |
| P409 | 사용자 함수의 필수 인자 누락 |
| P410 | 사용자 함수에 존재하지 않는 이름 인자 |
| P411 | 같은 인자를 위치·이름 또는 이름으로 중복 전달 |
| P412 | 함수 매개변수 기본값과 선언 타입 불일치 |
| P499 | 타입 검사기 내부 오류 (검사만 중단, 실행엔 영향 없음) |

타입은 **옵션**이다. 표기 안 하면 P4xx 는 절대 안 난다. `Any` 는 항상 통과.
